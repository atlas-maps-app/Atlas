# Licences in `:tiles`

No third-party source code is vendored here. Everything is Atlas's own code: the published packs' catalogue
(`packs.json`, Atlas's own format), their downloads, and a protobuf and a JSON reader.

Libraries used (from the Gradle catalog, not vendored): OkHttp and Okio (Apache-2.0), kotlinx.coroutines (Apache-2.0).

## Data

The packs it lists and downloads hold OpenStreetMap data: © OpenStreetMap contributors, under the ODbL.
