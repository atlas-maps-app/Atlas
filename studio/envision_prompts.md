# Envisioning prompts

A blank agent envisions a screen that should be imagined fresh; a screen that must fit what exists or stand on real data goes to an agent that knows the brief, the spec and the engine (the owner, 13 Oct). The rest of this file is about the blank one. A blank agent knows nothing of this project and cannot open its files; apart from that it has no constraints (user: "It should have no access to anything else from this project besides the prompt it gets" and "It should have no constrainst except not being able to access the projects project files and being a blank agent"). Use the agent type `blank` (`~/Documents/Claudea/.claude/agents/blank.md`): it has the web tools (WebSearch, WebFetch) and none that read this computer (no Read, Glob, Grep, Bash, Edit, Write). Run it at the highest effort for envisioning and merging alike. It loads only at session start: before its first real use, run one test and check the transcript for which tools it has and for any "instructions" attachment (the memory). The older Plan-type agents could read files, so they no longer count as blank.

The words and parts live in the Envisioning studio (https://claude.ai/artifact/91R7EDZTwhvELNpH6nvfSB, db `studio/config`). Build every prompt from them exactly as the user left them.

## How much to give

As little as possible, but the right things. Envisioning: a few words, the screen, the bare wrapper. A merge: the candidates, one line each on what is good in them, and the goal. Calm and warm are optional words, never defaults.

## Always

Android is for the prompt: it tells blank agents which phone to draw. Don't add "Android" when improving boards; where an original board says it, it stays.


- APP (no app name; the prompt never says "Atlas"): a maps app for anywhere, on Android. It finds places near each other (a café within 200 m of a park and a bike dock), and it tailors itself to you: your ways of going, your tastes, your pace.
- SCREEN: one line, e.g. "Go, the home of the Go tab: where to next, and how."
- FORMAT, no rules (owner: "For the technical wrapper a blank agent should get no rules"): "One phone screen, as one HTML file." Afterwards I fit what comes back into a 412 × 915 board: wrap it, scale it, and render any script to static HTML in the browser pane.

## Switches (vary from agent to agent)

- OPENER: "Envision a maps app rich in character, love and care." (the user's; best so far). Play: "Envision a new breakthrough maps app, rich in character, love and care."; "Envision a new breakthrough maps app." (plays: "a breakthrough maps app", "the maps app nobody has made yet")

- WORDS
  - A. Rethink: "Rethink the maps app. Fun, smart, caring, characterful. Visuals instead of text where they add value. Rich type. Blow me away."
  - B. Best yet: "The best maps app yet: the perfect hybrid of every maps app, without looking at any. Minimal and rich. Characterful, caring. Skeuomorph where it adds value. Take it further."
  - C. The user's set: "love · caring · characterful · soulful · artful · beautiful · elegant · minimal · rich · skeuomorph where it adds value · take it further · ahead of every maps app that exists · genuinely useful"
  - D. Few: "Fun. Smart. Caring. Visual. Blow me away."
  - Play: change a word's form, reorder, add or drop a word; the fewer, the freer.
- GOOD (sometimes): "What our best screens share: a real thing from the place carries the answer. One question, answered at a glance. Rich but calm; empty space stays empty. About you and the moment. Honest in a few words."
- OURS (sometimes): in words only, because a blank agent cannot open this computer's files, images included.
- FRAME (sometimes): the blank frame from the studio, a 412 × 915 screen as code with only the basic layout (status bar, back button; optionally sheet, main action, tab bar).
- PLACE (sometimes): a city or region, on any continent.
- MODEL (sometimes; user): the model a blank agent runs on, Opus 5.5 by default, or Sonnet 5.5, Fable 5.1, Haiku 4.5. Set in the studio's Prompt tab (Agents › Model, and per mix Settings › Model). With "Now and then another model" on, about one round in three runs one default mix on another model, Sonnet 5.5 first. Note in the trial log which model made which candidate and which won.

## Merge

A fresh blank agent gets the words, the candidates (images and HTML) and our own good screens for that job, and makes the one screen: the best of each, keeping what makes ours good, nothing unnecessary.
