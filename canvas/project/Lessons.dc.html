Borrowed well examplesTwo open-source Android apps already do parts of Atlas brilliantly. Here is what each gets right, what Atlas adopts, and what their licences allow.
Trail SenseMIT · Kotlin · Android · fully offline
WHAT IT GETS RIGHT
  • Never touches the internet, so everything works in the backcountry.
  • Uses the phone's sensors: barometer forecasts, clinometer, lightning distance, sun and moon.
  • Only features tested against real data or published science.
  • A tool, not a crutch: it tells you to carry a compass and the skills too.
  • Beacons, paths, backtrack, turn-back alerts, packing lists, photo maps.
WHAT ATLAS TAKES
Field kitPhoto mapOffline forecastTurn backPacking lists
How: MIT lets Atlas reuse code with the licence notice. Better still, share the sensor code upstream so both apps get better.
StreetCompleteGPL-3.0 · Kotlin Multiplatform · Android, iOS coming
WHAT IT GETS RIGHT
  • Anyone can improve OpenStreetMap by answering one simple question on the spot.
  • Quests appear only nearby and only where a survey is needed.
  • Overlays colour the map by what is known and what is missing.
  • AR measuring, re-checking old data, notes, and tidy changesets.
  • Works offline and is light on data.
WHAT ATLAS TAKES
QuestsOverlaysStill there? + ARKerbs for step-freeParking rules
How: GPL-3.0 means copying its code would make Atlas GPL too. Atlas either goes GPL, writes its own code from the same ideas and the public quest list, or hands deep edits over to StreetComplete itself.
